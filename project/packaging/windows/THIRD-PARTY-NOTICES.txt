CLIProxyAPI
===========

Upstream project: https://github.com/router-for-me/CLIProxyAPI
Pinned release: v7.2.132
Pinned commit: 78f0c4079e3e6273d65d03b5549cffc898703264
License: MIT (see LICENSE-CLIProxyAPI.txt)

This package uses a locally built CGO-disabled Windows amd64 binary. Dynamic plugins are
disabled and are not needed for the built-in Antigravity provider.

Local source modifications
--------------------------
The patch restricts OAuth to loopback, validates callback Host/state, adds PKCE S256, protects
Windows credentials with current-user DPAPI and atomic writes, bounds optional network probes,
disables package-managed background version lookup, preserves Gemini 3.7/3.8 output limits, reports
accurate model capabilities, and retries project propagation without unbounded auth-file reads.

The sanitized redistributable patch is included as CLIProxyAPI-v7.2.132-zcode.patch.
Run sanitize_upstream_oauth.go against a clean v7.2.132 tree before applying that patch;
the preprocessing step keeps removed upstream OAuth literals out of the patch text.

The API service is configured with host 127.0.0.1, plugins disabled, remote management and
its control panel disabled, and detailed request logging disabled. A random per-user key protects
the loopback-only management calls used by the local quota dashboard.

Windows Electron control center
===============================

The v1.0.1-test control center uses Electron 44, React, Tailwind CSS, and lucide-react.
Exact JavaScript versions and integrity hashes are recorded in ui/package-lock.json.
Electron's MIT license and Chromium third-party notices are shipped beside the executable
as LICENSE.electron.txt and LICENSES.chromium.html.

System tray
===========

The compatibility Go manager includes github.com/gogpu/systray v0.2.8.
Platform builds also link golang.org/x/sys (Windows) or github.com/go-webgpu/goffi
(macOS). Their required license texts are in LICENSE-TRAY-DEPENDENCIES.txt.
